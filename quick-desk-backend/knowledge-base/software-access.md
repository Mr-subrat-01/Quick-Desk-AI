# Software and Drive Access Request

## Requesting Software Access
If you need access to any company software or tool:
1. Email your manager with software name and reason
2. Manager forwards request to IT team
3. Access granted within 24 hours after approval

## Requesting Drive or Folder Access
For shared drive or folder access:
1. Email your manager with folder name and reason
2. Manager grants or delegates access
3. Access granted within 4 business hours

## Access Levels
- General tools — approved instantly for all employees
- Finance tools — requires Finance head approval
- Admin tools — requires Admin manager approval
- Developer tools — requires Tech lead approval

## Revoking Access
When employee leaves or changes department IT team
revokes all access automatically within 24 hours.

## Important
Never share your software credentials with anyone.
If you suspect unauthorized access contact your IT manager immediately.
